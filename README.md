# CI Academy — Computational Imaging Mathematics (ECE 60141, Purdue)

A personal study app for the Bouman course, built backward from the 2021–2025 midterms and forward from first principles. Four modules, each a nine-step pathway: prerequisites → intuition → visual lab → derivation → worked example → guided practice → independent problem → timed original exam question → feedback.

Live: **https://alfaj10408.github.io/ci-academy/**

| Module | Lectures | Exam questions |
|---|---|---|
| 1 · Causal AR → noncausal GMRF | 5, 7, 9–11 | 2021 Q3, 2022 Q2, 2025 P1 |
| 2 · Surrogate functions and MM | 18–20 | 2021 Q4, 2022 Q4, 2023 P3, 2024 P2 |
| 3 · MAP, gradient descent, ICD | 12–14 | 2021 Q2, 2022 Q4, 2023 P2, 2024 P1 |
| 4 · Proximal maps, ADMM, Plug-and-Play | 21–25 | 2022 Q3, 2023 P1, 2024 P3, 2025 P2, 2025 P4 |

The app source is in [`academy/`](academy/) (see its README for how to run and extend it); the planning notes are in [`docs/`](docs/). The course PDFs and the extracted text they were built from are deliberately not part of this repository.

Progress is stored in the browser (localStorage) and never leaves your machine.
